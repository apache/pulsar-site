Overview

Table of Contents
  • 1. What it provides
  • 2. Modules

Apache Pulsar support for Spring makes it easier to build Apache Pulsar applications with Spring. It brings familiar Spring concepts to Pulsar, such as templates, annotated listener methods and auto-configuration, so that your application can focus on its messages rather than on managing clients, producers and consumers.

This documentation is for version 3.0.0-M1-SNAPSHOT.

You are viewing documentation for a SNAPSHOT version (3.0.0-M1-SNAPSHOT). While it is usually in-sync with the underlying code, it is subject to change and not guaranteed to be up-to-date with the underlying code.

To start using it, continue to the Introduction. If you are moving an application from Spring for Apache Pulsar, which this project succeeds, see Migration from Spring’s Pulsar support.

1. What it provides

  • Publishing messages: PulsarTemplate publishes messages to a topic.

  • Consuming messages: @PulsarListener and @PulsarReader turn a method into a consumer or a reader of a topic.

  • Spring Boot: auto-configuration and starters set up these components from configuration properties.

  • Spring Cloud Stream: a binder connects event-driven applications to Pulsar.

  • Pulsar features: support for transactions, administration and Pulsar Functions.

  • Production and testing: observability with Micrometer, and utilities for tests.
